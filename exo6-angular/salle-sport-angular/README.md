SALLE SPORT ANGULAR

## Description

Application Angular pour gérer les adhérents d'une salle de sport.

## Fonctionnalités

- Afficher la liste des adhérents
- Ajouter un adhérent
- Voir les détails d'un adhérent
- Modifier un adhérent
- Pagination
- Validation des formulaires
- Gestion des erreurs HTTP

## Technologies

- Angular
- TypeScript
- HTML
- CSS
- Spring Boot
- MySQL

## Lancer le projet

Démarrer d'abord le backend Spring Boot sur :

http://localhost:8080
